## 技術監査
- [x] CPU、レジスタ、キャッシュ、RAM、補助記憶、NIC、OSの役割を区別した。
- [x] 命令実行の逐次モデルと現代CPUのパイプライン・投機実行を混同しない。
- [x] 高水準言語1行と機械語1命令を同一視しない。
- [x] プロセス・スレッド、割込み、DMA、ページフォルト、スワップの説明に条件を付した。
- [x] ページフォルトの全件がディスクI/Oを伴うとは記述していない。
- [x] CPU使用率と応答性能を分離し、SQL・I/O・ロック・ページングの待機を説明。
- [x] DBのCOMMIT・ログフラッシュ・耐障害性の保証は製品・設定依存と明示。
- [x] vmstatのr/b/waは概念的な読み方で、OS・版差と未実行を明示。
- [x] すべてのログ・数値は架空で、実機の測定結果と誤認させない。
